# Personal Portfolio

This repository contains my personal portfolio website created as part of my CSE 230 Web Design and Development coursework.

## About the Project

The portfolio is a single-page website built using semantic HTML5. It presents basic information about me, my technical skills, projects, and a contact form.

The page uses browser-default HTML layout without CSS or inline styling, as required by the assignment.

## Sections

The portfolio includes the following sections:

- **About Me** - A short introduction and profile image.
- **Technical Skills** - A descriptive list of my current technical skills.
- **Projects** - Links to two of my projects hosted on GitHub.
- **Contact Me** - A basic contact form with name, email, and message fields.

## Technologies Used

- HTML5
- Git
- GitHub
